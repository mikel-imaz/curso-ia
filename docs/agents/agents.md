# __Agentes de IA__: conceptos básicos

Este curso explica la diferencia entre los agentes de IA y las herramientas de automatización y chatbots tradicionales. Para ello describe sus componentes básicos (como la memoria, el uso de herramientas y la orquestación) y aporta las claves para decidir cuándo y cómo implementar soluciones basadas en agentes. Se emplean ejemplos (desde agentes de soporte al cliente a asistentes de programación) para enseñar qué es lo que hace que los sistemas de IA sean agentivos, mostrando cómo razonan, así como la manera responsable de usarlos.
